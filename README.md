# ФАКТ — мини-приложение для Telegram

Главная с покадровой анимацией на скролле, квиз из 5 шагов и смета с печатью «Оплата по факту».

Открывается кнопкой в Telegram-боте. Адрес приложения: https://berghhman.github.io/fakt-miniapp/

- `index.html` — всё приложение; настройки (название, `API_URL`, цены) — в блоке `CONFIG` и массиве `SERVICES`
- `frames/` — 139 кадров анимации
- `banner.png` — картинка для приветствия в боте
